
# Model Results

This folder contains the experimental results of the
Internet Comments Aggression Filtering project.

## Models

- TF-IDF + Logistic Regression
- DistilBERT

## Evaluation metrics

The models are evaluated using:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion matrix

Results are based on the Jigsaw Toxic Comment Classification dataset.
